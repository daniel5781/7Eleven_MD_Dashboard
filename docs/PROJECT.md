# 신상품 초기 출고량 예측과 발주 수량 검토

[모델 실행 안내](../modeling/README.md) · [코드 출처](../modeling/SOURCE_MAP.md) · [대시보드](https://daniel5781.github.io/7Eleven_MD_Dashboard/)

## 문제 정의

신상품은 판매 이력이 부족하고 상품·센터마다 예약 반응과 재고 소진 속도가 다릅니다.
예약량에 고정 배수를 곱하는 기준을 보완하기 위해 **초기 출고량을 예측하고 운영 시나리오를 비교**했습니다.

v6 모델의 타깃은 출시일부터 4일간의 센터 → 점포 출고량입니다.
실제 발주량, 점포 판매량과 구별합니다.
출고량 역시 재고 제약을 받을 수 있으므로 이를 무조건적인 수요나 최적 발주량으로 단정하지 않습니다.

## 1. 전처리와 피처

상품 × 센터 단위로 결정일까지의 예약량과 참여 점포를 집계합니다.
예약 속도·집중도, 센터 규모와 지역 비중, 상품 경제성, 과거 공동예약 유사상품 정보를 결합합니다.

공개본은 기존 33개 피처 명세를 유지하면서 원천 파일 읽기를 정규화 테이블 입력으로 바꿨습니다.
결정일 이후 마스터 변경, 교차센터 시점 차이, 이웃 출고 라벨 확정 지연을 명시적으로 다룹니다.

## 2. 모델링

기본 모델은 예약량 대비 출고 배수를 학습하는 LightGBM 5시드 앙상블입니다.
규모는 예약량으로 복원하고 모델은 상품·센터별 전환 배수를 학습합니다.

추가 실험은 배수·원수량·로그 타깃의 블렌드입니다.
검증 구간에서 결합 비중을 선택하며, 기본 전달 패키지와 별도로 평가합니다.
모델 구조의 차이를 합성 데이터 실행으로 비교할 수 있습니다.

## 3. 검증

- 상품의 결정일 순서에 따른 홀드아웃 분할.
- 다음 구간의 결정일까지 출고 라벨이 확정되지 않은 경계 데이터 제외.
- 직전 2개월을 검증 창으로 사용하는 월별 재학습 평가.
- WMAPE·MAPE·Bias와 과소·과다 발주 물량을 함께 확인.
- 누수 방지, 학습 전용 범주 사전, 모델 저장/복원과 입력 조건 검사.

α는 예측량에 곱하는 운영 시나리오 변수입니다.
공개본에서는 검증 구간에서 가정한 비대칭 비용을 최소화하는 값을 선택하며, 기업의 고정 권장값을 주장하지 않습니다.

## 4. 재고 시나리오

기준 공식, 재산정 공식, 모델 예측과 α 보정 수량을 같은 출고 시나리오에서 비교합니다.
일별 재고 수량 보존을 확인하고 미충족 요청 물량, 잔여 재고와 보유량을 계산합니다.
별도로 초과분의 소진 기간을 가정한 박스·일 부담을 비교합니다.

공개 시뮬레이션은 추가 입고·백로그가 없는 단순 예제입니다.
원본 장기 물류 시뮬레이션 전체의 재현이나 실제 비용 절감 실적을 의미하지 않습니다.

## 5. 의사결정 화면

예약 추이 → 모델 추천량 → MD 수량 조정 → 센터별 배분을 확인하는 React 대시보드입니다.
이 화면 흐름과 공개 Python 모델 예제는 별도로 실행됩니다.
공개 웹은 독립된 합성 JSON을 읽으며 Python 실행 결과를 자동 반영하지 않습니다.
모델 출력을 화면에 연결할 때 필요한 상품·센터 키와 수량 단위 변환은
[출력과 대시보드 연결](../modeling/README.md#출력과-대시보드-연결)에 정리했습니다.

## 개인 기여와 공개 범위

| 담당 | 설명 |
| --- | --- |
| PM | 프로젝트 진행 관리와 결과물 연결 |
| 데이터 전처리 | 모델 검증에 사용할 분석 단위와 입력 데이터 준비 |
| 예측 모델 검증 | 예측 시점, 데이터 분할, 오차와 운영 지표 점검 |
| 재고 시뮬레이션 | 발주 수량 변화에 따른 재고 운영 결과 비교 |
| 대시보드 구현 | 분석 결과를 발주 검토 화면에 연결하는 구현 참여 |

모델과 대시보드는 팀 프로젝트의 맥락을 함께 소개합니다.
공개 코드의 재구성 범위는 [SOURCE_MAP](../modeling/SOURCE_MAP.md)에,
원본 대시보드 작성 이력은 [팀 저장소](https://github.com/Geonhohoho/7Eleven_MD_Dashboard)에 연결했습니다.
블렌드는 팀원 모델 보고서를 참고해 검증한 협업 결과이며, 공개용 재구성을 당시의 개인 단독 개발로 소개하지 않습니다.

실제 기업 데이터, 기존 모델 가중치·예측표, 내부 보고서·발표 자료와 원본 Git 이력은 포함하지 않습니다.
모든 공개 실행 수치는 합성 데이터의 예제입니다.
