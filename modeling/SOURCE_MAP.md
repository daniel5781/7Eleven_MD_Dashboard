이를 개인 단독 창안으로 표현하지 않습니다.

## 공개용 변경

- **기업 파일 읽기 제거:** 원천 파일명·실제 센터 식별자·절대경로를 제거하고 정규화 DataFrame 입력으로 재구성했습니다.
- **독립 합성 데이터:** 직접 만든 생성 규칙만 사용합니다. 원자료의 샘플링·익명화·분포 추정 결과가 아닙니다.
- **시점 처리 강화:** 마스터와 센터 규모를 결정일 이전 스냅샷으로 선택하고 상품 전체에 같은 예약 컷오프를 적용합니다.
- **이웃·prior 가용성:** 단순히 먼저 출시된 상품이 아니라 4일 라벨까지 확정된 과거 상품만 참조합니다. 원본의 고정 train prior·전년도 CF 대신 시점별 이력 집계를 사용합니다.
- **학습 경계:** 다음 구간의 첫 결정 시점에 알려지지 않은 라벨을 학습·검증에서 제외합니다.
- **입력 오류 처리:** 누락 피처, 예약 0, 무한대와 미학습 상태를 명시적 오류로 처리합니다. 새 범주는 학습 범주 사전에 따라 결측으로 처리합니다.
- **α 기본값:** 원본의 고정 운영 권장값 대신 검증에서 선택한 값을 사용합니다. 과소·과다 비용 비중은 공개 예제의 가정입니다.
- **블렌드 순서:** 원본은 시드마다 가중치를 고른 뒤 평균합니다. 공개본은 타깃별 시드 평균을 먼저 만든 뒤 하나의 검증 가중치를 고릅니다.
- **재고 비교:** 원본 초과재고 개념을 보존하되, 소진 기간 상한이 걸릴 때와 출고율이 0일 때의 면적 계산을 일반화했습니다. 일별 수량 보존 시뮬레이션은 공개 예제로 추가했습니다.
- **실행 환경:** Python 3.13·LightGBM 4.7.0에 맞춰 정리하고, CLI 예제는 트리 수를 줄여 실행 시간을 제한했습니다.

따라서 원본 기업 데이터로 측정한 점수와 이 패키지의 합성 점수는 직접 비교할 수 없습니다.
